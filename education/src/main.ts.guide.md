# 🧩 Configuration: `main.ts`

> [!abstract] File Overview / 文件概览
> `main.ts` is the primary entry point of the Vue application. It is the first script executed by the browser. Its responsibility is to bootstrap the Vue engine, inject global plugins (like Pinia and Router), and mount the root component onto the HTML document.
> `main.ts` 是 Vue 应用程序的主要入口点。它是浏览器执行的第一个脚本。它的职责是引导 Vue 引擎，注入全局插件（如 Pinia 和 Router），并将根组件挂载到 HTML 文档上。

---

> [!multi-column|no-wrap]
>
>> [!code] Source Code
>> ```typescript
>> import './assets/main.css'
>>
>> import { createApp } from 'vue'
>> import { createPinia } from 'pinia'
>>
>> import App from './App.vue'
>> import router from './router'
>>
>> const app = createApp(App)
>>
>> app.use(createPinia())
>> app.use(router)
>>
>> app.mount('#app')
>> ```
>
>> [!note] Architectural Breakdown
>>
>> ## 🏗️ 1. Core Logic & Architecture (核心逻辑与架构)
>>
>> ### Global Asset Injection
>> - `import './assets/main.css'`: Injects global styling that resets browser defaults and sets up the root `html/body` dimensions (critical for full-screen applications like MapLibre).
>>
>> ### Application Bootstrapping
>> - `createApp(App)`: Creates the Vue application instance, using `App.vue` as the root blueprint.
>>
>> ### Plugin Ecosystem (`app.use`)
>> - `app.use(createPinia())`: Installs the Pinia state management system globally.
>> - `app.use(router)`: Installs Vue Router globally.
>>
>> ## ⏳ 3. Lifecycle & DOM Interaction (生命周期与DOM交互)
>>
>> ### Mounting (`app.mount`)
>> - `app.mount('#app')`: This is the crucial final step. It tells the Vue engine to take control of the HTML element in `index.html` that has `id="app"`. Vue renders the virtual DOM generated by `App.vue` into this physical DOM node.
>>
>> ## 🚨 4. Pitfalls, Bugs & Performance (陷阱、Bug与性能优化)
>>
>> > [!warning] CSS Import Order / CSS 导入顺序
>> > **Issue:** The order of CSS imports in `main.ts` matters significantly. If you import a UI library (like Element Plus) *after* your custom `main.css`, the library's default styles might accidentally override your custom global rules.
>> > **Fix:** Ensure base layout/reset CSS files are imported first.
